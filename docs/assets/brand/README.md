# Headwater brand assets

Three source streams bend on matching arcs into a single channel: many
upstream data sources, one API. All files are generated from one geometry;
text is converted to outlines (Inter SemiBold, SIL Open Font License 1.1), so
no SVG depends on an installed font.

| File | Use |
|---|---|
| `headwater-logo-light.svg` / `.png` | Horizontal logo on light backgrounds |
| `headwater-logo-dark.svg` / `.png` | Horizontal logo on dark backgrounds |
| `headwater-mark-light.svg` | Mark only, light backgrounds |
| `headwater-mark-dark.svg` | Mark only, dark backgrounds |
| `headwater-icon.svg`, `-512.png`, `-1024.png` | App icon, avatar, favicon (rounded square) |
| `headwater-social-preview.svg` / `.png` | 1280x640 social card (GitHub: Settings > Social preview): the five sources flowing into one API, a real request/response, key features |
| `headwater-social-preview-simple.svg` / `.png` | Minimal 1280x640 card: logo, tagline, URL |

## Colours

| Role | Hex |
|---|---|
| Navy (text, icon background) | `#0B2545` |
| Mark gradient, light backgrounds | `#06B6D4` to `#1D4ED8` |
| Mark gradient, dark backgrounds | `#22D3EE` to `#3B82F6` |
| Text on dark backgrounds | `#E6EDF3` |

## Usage

- Keep clear space around the logo at least the width of one stream
  (about 1/12 of the mark's height).
- Don't recolour the gradient, stretch the logo, or separate the wordmark from
  the mark in the horizontal logo. Use the mark or icon alone where the name is
  already shown.
- Below 24 px, use `headwater-icon.svg`: its solid background keeps the
  streams legible at favicon size.
