# NOTE: slowapi is deliberately NOT a dependency. main.py used to import it
# behind a try/except and build a Limiter keyed by remote address; that path
# was dead in every deployment, and had it been live it would have keyed
# limits by IP -- the exact CRT-8 defect app/core/rate_limiter.py fixes.
# The dead path was removed rather than fed. Rate limiting is entirely
# app/core/rate_limiter.py, which has no third-party limiter dependency.

# Metrics. main.py builds an Instrumentator and exposes /metrics (API-key
# gated), but both packages were undeclared, so every deployment ran with
# METRICS_AVAILABLE=False -- the README advertised a feature that had never
# once executed. Declaring them is what makes the documented behaviour real.

prometheus-fastapi-instrumentator==8.1.0
